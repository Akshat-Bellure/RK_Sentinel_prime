# RK Sentinel Prime 🛡️

**Region Locked:** `ap-south-1` (Mumbai)  
**Classification:** Internal / Audit-Grade  
**Version:** 1.2.0-PILOT

## 📖 Overview
Sentinel Prime is a procurement intelligence platform designed for Indian government tenders (GeM/CPPP). It features:
- **RFP Analyzer**: Risk scanning (Data Residency, Restrictive Clauses).
- **Pre-Bid Studio**: Drafting queries with verified legal citations (GFR 2017).
- **Evidence Vault**: Secure, encrypted storage for compliance documents.
- **L1 Calculator**: Make-in-India (Class-I/II) calculation engine.
- **Legal Gate**: 2FA-enforced sign-off for all exports.

## 🚀 Developer Quick Start

### Prerequisites
- Docker & Docker Compose
- Go 1.21+
- Node.js 18+
- Python 3.9+
- AWS CLI (configured for `ap-south-1`)

### 1. Start Mock Infrastructure
```bash
# Starts Postgres, VectorDB, and LocalStack (S3/KMS)
docker-compose up -d
```

### 2. Run Backend (Go)
```bash
cd backend
export AWS_REGION=ap-south-1
export JWT_SECRET="dev-secret-do-not-use-in-prod"
go run main.go
# Server active at http://localhost:8080
```

### 3. Run AI Core (Python)
```bash
cd ai
pip install -r requirements.txt
uvicorn main:app --port 8000
# AI Service active at http://localhost:8000
```

### 4. Run Frontend (React)
```bash
npm install
npm run dev
# Dashboard active at http://localhost:3000
```

## 🛑 Staging vs Production Checklist

**WARNING: Failure to follow this checklist is a security violation.**

| Step | Action | Staging (Dev) | Production (Live) |
|------|--------|---------------|-------------------|
| 1 | **Data Residency** | `ap-south-1` preferred | **MANDATORY** (`ap-south-1`) |
| 2 | **Developer Auth** | `Sentinel_Developer` allowed | **REMOVE ACCOUNT** (Must fail login) |
| 3 | **Secrets** | `.env` files ok | AWS Secrets Manager **ONLY** |
| 4 | **2FA Policy** | Optional | **ENFORCED** for Admin/Legal |
| 5 | **Logs** | Console/File | CloudWatch Immutable Append-Only |
| 6 | **Evidence** | Local Mock Storage | S3 Bucket + KMS Encryption |

## 📜 Legal & Compliance
- All citations generated by the AI must be **Double-Blind Verified** against the Knowledge Base.
- No instructions to bypass CAPTCHAs or Portal Protections are allowed.
- Pre-bid queries regarding "Restrictive Conditions" must cite **CVC Circular 03/01/18**.
