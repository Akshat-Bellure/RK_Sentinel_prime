# Sentinel Prime Embeddings Module

This module handles the vectorization of tender clauses using local, region-compliant models.

## Model Details
*   **Model**: `sentence-transformers/all-MiniLM-L6-v2`
*   **Type**: Local / Open Source (HuggingFace)
*   **Dimensions**: 384
*   **Deployment**: Baked into Docker image (No runtime internet access required for model weights).
*   **Compliance**: `ap-south-1` data residency compliant (Text never leaves the container).

## Vector Store
*   **Technology**: ChromaDB
*   **Configuration**: Persistent storage volume.

## Usage

### 1. Build & Run Infrastructure
From the project root:
```bash
docker-compose -f infra/docker-compose.yml up -d --build
```

### 2. Generate Embeddings (Ingest)
Runs the `build_embeddings.py` script inside the worker container.
```bash
docker-compose -f infra/docker-compose.yml run embeddings-worker python build_embeddings.py --input sample_data/tender_index_sample.json --reset
```

### 3. Test Retrieval
Query the vector index for similar clauses.
```bash
docker-compose -f infra/docker-compose.yml run embeddings-worker python retrieve.py --query "data residency requirements in India"
```

## Sample Data
Input JSON is expected in the format generated by the `parser` service.
Output vectors are stored in ChromaDB. 

**Sample Vector Structure (Internal):**
```json
{
  "id": "GEM/2024/B/SAMPLE-01_CL-4.2",
  "embedding": [0.032, -0.102, 0.442, ...], // 384 floats
  "metadata": {
    "tender_id": "GEM/2024/B/SAMPLE-01",
    "type": "TEXT"
  }
}
```
